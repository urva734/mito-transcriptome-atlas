# Module 05: Disease Association - MELAS

**Variant:** m.3243A>G in MT-TL1 (tRNA-Leu UUR)
**File:** ../results/melas_mutation.txt

**Mechanism:**
- WT: A-U pair in D-loop, stable cloverleaf
- Mutant: G-U wobble, destabilized
- Loss of taurine modification at U34
- Impaired aminoacylation -> stalled translation

**Impact:** ND6/COX deficiency, Complex I/IV defect, lactic acidosis. Severity >60% heteroplasmy.

**Phenotype:** MELAS - stroke-like episodes, myopathy, encephalopathy.

**Conclusion:** Single base change disrupts RNA structure -> OXPHOS failure.

Ref: Goto et al. Nature 1990.
